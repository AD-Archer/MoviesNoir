# Movies Noir Random Movie Generator

Movies Noir is a web platform dedicated to celebrating and sharing Black culture through television and film. Built with Vue 3 and Vite, this site serves as a community space for discovering, discussing, and appreciating Black representation in media.

## About

Movies Noir provides a curated space for:
- Discovering Black-led TV shows and movies
- Sharing perspectives on Black representation in media
- Building community through shared cultural experiences
- Highlighting both classic and contemporary Black cinema

## Random Movie Generator

The **Random Movie Generator** is a feature developed for Movies Noir to help users discover exciting new content from our collection. By interacting with the Movies Noir website, users can generate suggestions for movies or TV shows that align with our theme of showcasing Black culture.

If you wish to contribute or modify the Random Movie Generator, please visit the dedicated repository: [MoviesNoir-Movie-Generator](https://github.com/AD-Archer/MoviesNoir-Movie-Generator).

## Technical Stack

This project is built with:
- Vite
- React
- Bootstrap
- Font Awesome

## Development

To get started with development:

1. Clone the repository:
   ```sh
   git clone https://github.com/AD-Archer/MoviesNoir.git
   ```
2. Navigate to the project directory:
   ```sh
   cd movies-noir
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
4. Run the development server:
   ```sh
   npm run dev
   ```
